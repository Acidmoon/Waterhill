# 从零开始的能工智人生活-认识你的电脑
> **前言**
本系列文章面向计算机与AI相关零基础的朋友，目的是让读者阅读实践后可以更好地驾驭电脑与如今的AI，受本人精力与能力限制，文章内容难免出现纰漏与不足，望读者在阅读时合理使用网络搜索工具进行深入了解。

## 电脑里的东西，到底放在哪里了？

你可能每天都在用电脑——刷网页、写作业、看视频、用微信。

但你可能从来没有问过自己一个问题：**我存在电脑里的东西，到底放在哪里了？**

如果你曾经遇到过这些情况，这堂课就是为你准备的：
- 下载了一个文件，然后找不到了
- 桌面堆满了各种乱七八糟的东西，想整理又无从下手
- 想建一个文件夹管理资料，结果右键菜单不知道点哪个
- 别人说起「C 盘」「D 盘」「路径」这些词，你听不懂但又不好意思问

这堂课的目标很简单：**让你从「会用电脑」变成「能管好电脑」**

## 第一部分：文件系统——你的电脑是一座图书馆

### 1.1 底层逻辑：为什么叫「文件系统」？

计算机里的一切，本质上都是**文件**。

一张照片是一个文件，一个 Word 文档是一个文件，一首歌是一个文件。

那么问题来了：如果你有几千个文件，怎么才能找到想要的那个？

答案就是根据**文件夹（也叫目录）**去寻找。

你可以把电脑理解成一座图书馆：

| 计算机概念 |图书馆类比 |
|------------|------------|
|磁盘（C 盘、D 盘） |一栋楼（不同的楼，比如教学楼、图书馆楼） |
|文件夹 |楼层里的房间 |
|子文件夹 |房间里的书架 |
|文件 |书架上的书 |
|路径 |地址：哪栋楼 → 几楼 → 几号房 → 第几个书架 |

所以当你把一个文件保存在 `D:\大学资料\课程表.xlsx`，就相当于说：**去 D 栋楼 → 「大学资料」房间 → 拿起「课程表」那个本子**。

有同学可能要问了`D:\大学资料\课程表.xlsx`这是个什么东西？我只想要我的课程表，为什么前面会有一个`D:\`什么的？

这个`D:\大学资料\`就是我们所说的路径，就像写信需要填写收信人的地址，在电脑上寻找文件也需要知道文件在哪儿。

当我们从浏览器下载一个文件到电脑时，往往是下载到了浏览器的默认存储路径。下面我来演示如何查找自己浏览器的默认下载路径。

我使用的是Microsoft Edge浏览器，我们可以点击`Alt + F`来打开设置栏![设置.png](/assets/images/02aa62b4c74648a19a2d1f098d2040b6.png)然后点击**设置**进入设置页面![设置2.png](/assets/images/c23fd60b7e9846c49537f3357676e98e.png)

接下来点击**下载**进入查看你的默认保存路径。![设置3.png](/assets/images/8aac8fd0b2d549f4a8ab54114d6e4f18.png)
如图，我的下载路径被我自定义为`E:\下载1\浏览器下载`，因此如果我们保存了一张图片或者下载了一个文件，我们就需要去`E:\下载1\浏览器下载`寻找我们的文件。

## 1.2 如何寻找文件？
我们已经下载了一份《暗淡蓝点》的图片（中间的圆圈是标注的，用于指示地球位置）![9825bc315c6034a85edfbf249a4a5e540923dd54d847.webp](/assets/images/fe5ec7e589944116a56216e1e15ff4eb.webp)那么我们去哪儿找到它呢？

这时候我们需要使用Windows的**文件管理器**来进行处理。顾名思义，它就是用来帮我们管理文件的应用。

首先，在你的桌面上找到**文件管理**或者**我的电脑**，当然最推荐的还是快捷键`Win（徽标键） + E`唤起文件管理器。![文件管理1.png](/assets/images/bac9122ff1f347058d3bb52cff4e46e9.png)当然你的电脑的文件管理器的侧栏应该没有这么多的固定项目，左侧栏向下滑动找到**此电脑**，根据我们上面知道的路径进行选择文件夹并打开。![文件管理2.png](/assets/images/067cdb8317bf473d9dd7a2281b7c1a9c.png)![文件管理3.png](/assets/images/16feff564115472aabdc1111ef619db1.png)于是我们就找到了我们的图片。双击打开即可。

## 1.3 右键菜单

在 Windows 里，**右键点击**是最常用的操作之一。在文件或文件夹上点右键，会弹出一个菜单，里面有各种可以对这个东西做的事情。 (╹ڡ╹)

我们按照使用频率，把右键菜单里的功能分成三个等级：

### 基础操作（必须掌握）

| 功能 | 怎么用 | 作用 |
| --- | --- | --- |
| **新建 → 文件夹** | 空白处右键 → 新建 → 文件夹 | 创建一个新文件夹，然后给它取个名字 |
| **重命名** | 在一个文件夹或文件上右键 → 重命名 | 改名字，也可以选中文件后按 `F2` |
| **删除** | 右键 → 删除，或选中后按 `Delete` | 送到回收站，还可以恢复 |
| **复制 / 粘贴** | 右键 → 复制，再到目标位置右键 → 粘贴 | 把文件复制一份到别的地方 |

### 进阶操作（让效率翻倍）

| 功能 | 怎么用 | 什么时候用 |
| --- | --- | --- |
| **剪切** | 右键 → 剪切，再到目标位置右键 → 粘贴 | 想把文件移动到另一个文件夹（而不是复制），相当于「搬家」 |
| **发送到 → 桌面快捷方式** | 右键 → 发送到 → 桌面快捷方式 | 不想把文件移走，但想在桌面上快速打开它 |
| **固定到「快速访问」** | 右键 → 固定到「快速访问」 | 把一个常用文件夹放在资源管理器最上面，随时一键到达 |
| **查看 → 详细信息** | 文件夹空白处右键 → 查看 → 详细信息 | 看到每个文件的大小、修改日期、类型，方便找文件 |
| **排序方式** | 空白处右键 → 排序方式 → 按名称/修改日期/大小 | 让文件按你想要的顺序排列 |

部分操作对应的快捷键，例如**复制**的`Ctrl + C`和**粘贴**的`Ctrl + V`之后大家会慢慢地形成肌肉记忆。

### 高手操作

| 功能 | 说明 |
| --- | --- |
| **在终端中打开** | Windows 11 里，按住 Shift 键再在文件夹空白处右键，会出现「在终端中打开」——这个我们后面会用到 |
| **属性** | 右键 → 属性，可以看到一个文件/文件夹的详细信息：位置、大小、创建时间、是不是只读等 |
| **撤销重命名/撤销删除** | 空白处右键 → 撤销，或按 `Ctrl + Z` 手滑了？可以反悔 |

## 第二部分 路径
### 2.1 路径的每个部分是什么意思

我们来拆解一个完整路径：

```
D:\大学四年\大一上\课程资料\课程表.xlsx
```

| 组成部分 | 含义 | 类比（地址） |
| --- | --- | --- |
| `D:` | **盘符**——你的硬盘被分成了好几个区，每个区有一个字母 | 「湖北省」 |
| `\` | **根目录**——这个盘的起点 | 省内的「武汉市」 |
| `大学四年` | 第一层文件夹 | 「光谷大道」 |
| `\` | 分隔符，表示「里面的」 | 「XX 号」 |
| `大一上` | 第二层文件夹 | 「XX 小区」 |
| `\` | 还是分隔符 | 「XX 栋」 |
| `课程资料` | 第三层文件夹 | 「XX 室」 |
| `\` | 还是分隔符 | —— |
| `课程表.xlsx` | 最终的文件名 | 目标人「张三」 |

所以 `D:\大学四年\大一上\课程资料\课程表.xlsx` 翻译成快递地址就是：**湖北省武汉市光谷大道XX号XX小区XX栋XX室 张三收**。

你会发现路径里有两个关键符号：

- **反斜杠 `\`**：路径的分隔符，表示「从 A 到 B」（Windows 用反斜杠，Mac 和 Linux 用正斜杠 `/`，这是历史遗留问题）
- **冒号 `:`**：跟在盘符后面，表示「这是哪一个硬盘分区」

### 2.2 绝对路径 vs 相对路径

这是路径概念里**最关键**的一个区分，也是很多初学者最容易迷糊的地方。

#### 绝对路径：从根开始的完整地址

绝对路径是从**盘符根目录**开始写，一直写到目标文件/文件夹。

```
D:\大学四年\大一上\课程资料
```

这就像快递地址：从省写到市写到区写到街道写到门牌号——不管你在哪里，拿着这个地址都能找到。

绝对路径的特点：

- 以盘符开头（`C:`、`D:` 等）
- 完整、不依赖你当前的位置
- 在任何时候、任何地方用这个路径都能找到同一个东西

#### 相对路径：从当前位置开始的简短地址

相对路径是**相对于你当前所在的位置**来写。

假设你当前在 `D:\大学四年` 这个文件夹里：

| 你想去的地方 | 绝对路径 | 相对路径 |
| --- | --- | --- |
| 大一上 | `D:\大学四年\大一上` | `大一上` 或 `.\大一上` |
| 课程资料 | `D:\大学四年\大一上\课程资料` | `大一上\课程资料` |
| 大一下 | `D:\大学四年\大一下` | `大一下` 或 `.\大一下` |
| D 盘根目录 | `D:\` | `..\`（上一级再上一级） |

看到了吗？当你在 `D:\大学四年` 里时，你不需要写完整的 `D:\大学四年\大一上`，只需要写 `大一上` 就行了——因为电脑知道你现在在 `D:\大学四年` 里，你只需要告诉它「再往下走一层」。

这就像你站在一栋楼的大厅里说「我去301室」，不需要说「湖北省武汉市……xx小区3栋301室」——因为「当前的位置」已经帮你省略了一长串。

#### 两个特殊的目录名

在任何路径里，有两个特殊的名字：

| 符号 | 含义 | 例子 |
| --- | --- | --- |
| `.` | 当前目录（我自己所在的这个文件夹） | `D:\大学四年\.` 就是 `D:\大学四年` |
| `..` | 上一级目录（父文件夹） | `D:\大学四年\大一上\..` 就是 `D:\大学四年` |

这两个符号在终端里非常有用——我们在下一篇文章就会用到。
