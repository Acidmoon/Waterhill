# Transformer架构

## 注意力机制

注意力机制来源于计算机视觉(CV)领域，其核心思想为当我们关注一张照片的时候，往往⽆需看清楚全部内容⽽仅将注意⼒集中在重点部分即可。⽽在⾃然语⾔处理领域，我们往往也可以通过将重点注意⼒集中在⼀个或⼏个 token，从⽽取得更⾼效⾼质的计算效果。

传统的神经网络有三种核心架构：

- **全连接神经网络(Feedforward Neural Network,FNN)**<br>每一层的神经元都和其上下两层的神经元完全连接。

- **卷积神经网路(Convolutional Neural Network,CNN)**<br>使用训练参数量远小于全连接神经网络的卷积层来进行特征提取和学习。

- **循环神经网络(Recurrent Neural Network,RNN)**<br>能够用历史信息作为输入，包含了环和自重复的网络。

因为NLP的任务往往需要处理序列文本，因此专门用于处理序列、时序数据的RNN往往在NLP任务上取得最优效果。在注意力机制出现之前，RNN及其衍生架构LSTM是NLP的霸主，如前面提到的ELMo就是使用的双向LSTM架构。

但是RNN以及LSTM有两个难以弥补的缺点：

- 并行计算能力受限。由于序列数据需要依次输入依序计算，导致GPU并行计算的能力受到极大的限制。因此，虽然RNN的训练参数量不大，但是计算时间成本却很高。

- 难以捕捉长序列的相关关系。距离越远的输入之间的关系越难以被捕捉。

针对这样的问题，Vaswani 等学者参考了在 CV 领域被提出、被经常融⼊到 RNN 中使⽤的注意⼒机制（Attention），创新性地搭建了完全由注意⼒机制构成的神经⽹络——Transformer，也就是⼤语⾔模型（Large Language Model，LLM）的⿐祖及核⼼架构，从⽽让注意⼒机制⼀跃成为深度学习最核⼼的架构之⼀。

注意⼒机制有三个核⼼变量：Query（查询值）、Key（键值）和 Value（真值）。我们可以通过⼀个案例来理解每⼀个变量所代表的含义。例如，当我们有⼀篇新闻报道，我们想要找到这个报道的时间，那么，我们的 Query 可以是类似于“时间”、“⽇期”⼀类的向量（为了便于理解，此处使⽤⽂本来表示，但其实际是稠密的向量），Key 和 Value 会是整个⽂本。通过对 Query 和 Key 进⾏运算我们可以得到⼀个权重，这个权重其实反映了从 Query 出发，对⽂本每⼀个 token 应该分布的注意⼒相对⼤⼩。通过把权重和 Value 进⾏运算，得到的最后结果就是从 Query 出发计算整个⽂本注意⼒得到
的结果。

具体⽽⾔，注意⼒机制的特点是通过计算 Query 与Key的相关性为真值加权求和，从⽽拟合序列中每个词同其他词的相关关系。

## 深入理解注意力机制

假设我们有一个字典：
```JSON
{
    "apple":10,
    "banana":5,
    "chair":2
}
```
那么字典的键值就是Key，字典的值就是Value。如果我们要查询Query为"apple"，那么我们可以把Query和Key做匹配来得到Value。

但是如果我们要查询的Query是包含了多个Key的概念呢？如果我们要查询"fruit"，我们应该得到apple和banana，不能得到chair。因此我们会选择将Key对应的Value进行组合得到最终的Value。

Query为"fruit"，我们将三个Key赋予如下的权重：
```JSON
{
    "apple":0.6,
    "banana":0.4,
    "chair":0
}
```
那么我们最终查询到的Value为：
$$
value = 0.6\*10+0.4\*5+0\*2 = 8
$$

上面的权重就是**注意力分数**。但是为了查询到Query，我们应该给每一个Key分配多少注意力，如何计算出注意力分数是一个问题。

从直观上来说，我们认为Key与Query的相关性越高，其注意力权重越大，但是如何得到合理的正确的计算注意力分数的方法呢？

我们之前介绍过**词向量**的概念，通过合理的训练拟合，词向量可以表征语义信息，让语义相近的词在向量空间中距离更近。词向量的相似性往往用欧氏距离衡量，但我们也可以使用点积来度量：
$$
v\cdot w = \sum_i v_i w_i
$$

因此语义相似的两个词对应的词向量的点积大于零，不相似的点积小于零。

那么假设我们的$Query =\text{furit}$ 对应的词向量为$q$，$Key$对应的词向量为$k = [v_{apple},v_{banana},v_{chair}]$，我们计算Query和每个Key的相似程度：
$$
x = qK^T
$$
此处K是所有Key对应的词向量的矩阵。我们得到的x反映了Query和每一个Key的相似程度。我们再用Softmax函数将其转哈为和为1的1权重：
$$
softmax(x)_i = \frac{e^{x_i}}{\sum_j e^{x_j}}
$$
此时我们就得到了注意力分数。最后我们再将注意力分数和1值向量做乘积即可。根据上述过程我们得到了注意力机制的计算公式：
$$
attention(Q,K,V) = softmax(qK^T)v
$$
此时的值还是一个标量，我们将值转化为维度为$d_v$的一个向量，同时查询多个Query，将多个Query对应的词向量组成矩阵$Q$，得到：
$$
attention(Q,K,V) = softmax(QK^T)V
$$
我们距离最后的标准的注意力机制公式还差最后一步：在上⼀个公式中，如果 Q 和 K 对应的维度  ⽐较⼤，softmax 放缩时就⾮常容易受影响，使不同值之间的差异较⼤，从⽽影响梯度的稳定性。因此，我们要将 Q 和 K 乘积的结果做⼀个放缩：
$$
attention(Q,K,V) = softmax(\frac{QK^T}{\sqrt{d_k}})V
$$
