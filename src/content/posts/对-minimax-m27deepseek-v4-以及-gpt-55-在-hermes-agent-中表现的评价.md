大体上，我就是想聊聊最近把这几款模型接进 Hermes Agent 时的一些真实感受。

### MiniMax M2.7

去年 MiniMax M2.5 刚出的时候非常厉害。那会儿 Agent 还没现在这么火，但 MiniMax 的产品就已经有了当时很少见的“操作电脑”能力——在网页端就能直接使用服务器上的命令行，编辑文件、收发文件，这点在当时挺难得的。我当时觉得 M2.5 非常好用，还给身边的朋友推荐过，结果被一位朋友呛了一句，大意是“小厂、野鸡厂”之类的。那时候 Kimi 的 K2.5 应该也出了，我试了一下，感觉很一般。我一直都不太喜欢 Kimi 和豆包：Kimi 感觉幻觉率很高，喜欢胡说八道；豆包就是单纯的笨。

说回 MiniMax。我也忘了 M2.7 到底是什么时候出的，但它出来的时候我大概率没接着用，因为当时正在用阿里的千问——千问 3.5 那阵子还是很能打的，春节期间出了 3.6，我又在疯狂用 3.6，当时开的是阿里百炼的 Coding Plan。所以整个过年那段时间，我都没怎么关注 MiniMax。后来阿里百炼取消了 Lite 档位的订阅，我忍无可忍，直接开了 GPT 的 Plus 套餐，一直用到现在。

转折发生在最近。我租了个云服务器，搭了个中转站，还在服务器上养了匹马、建了这个博客。这么一搞就发现 GPT 真的好慢——首 token 的延迟太长，思考时间也久，上下文又窄，用起来总觉得不太爽。于是我又把目光转回国内。之前老看到有人说 MiniMax M2.7 挺厉害，我就去看了它的 Token Plan，入门最低档位我记得是 30 块。三天前我开了一个，然后接入了我的 Hermes Agent。

结果让我大跌眼镜——**菜的没边了**。先不说它能力怎么样，它连系统提示词里要求加载的那些 skill 都不加载，我是真绷不住了。问它为什么不加载，它说“是因为懒”，哎…… 实际用它改代码什么的，也感觉非常菜。所以这套餐我以后不会再订了，除非它以后专门出一个深度优化 Agent 调用的模型。总之，M2.7 在 Agent 里的使用体验，就是菜的没边了。

### GPT 5.5

GPT 一直都是近似全能战士，什么都能干，而且都挺厉害。我平时写代码基本都用 GPT，因为我写的东西不涉及太多前端，所以它给我的感觉一直是非常强、非常能打。在 Hermes Agent 里面，它综合水平依然是最强的：每次都会老老实实加载 skill，严格按照提示词来做，指令遵循程度我觉得很好。

唯一不满意的地方，就是有点慢。可能是我的中转站的原因，总之它在 Agent 里的响应速度让我不太爽。所以现在我只有在修那种 DeepSeek V4 修不了的 bug，或者 DeepSeek V4 暴露出一些架构缺陷时，才会把 GPT 拉出来补位。一句话总结：**它依旧是全能手**。

### DeepSeek V4

坦白说，我对 V4 Flash 的评价要高于 V4 Pro。

V4 Flash 现在说白了跟免费没什么区别，一块钱一千万 Tokens，性能却比 M2.7 好得多。它听得懂话，改一些简单代码也改得明白，最重要的是——快是真的快。GPT 可能要等上半分钟才能搞定的事情，Flash 很快就跑完了，而且执行质量也还行。所以我觉得 Flash 非常棒。

那 Pro 呢？作为万亿参数的模型，它的代码能力多少有些配不上自己的参数量。前端审美方面，V4 Pro 确实很厉害，我这个博客的前端全部都是它写的，鼠标点击的水滴特效也是它一次就写好的，前端能力没得喷。但后端能力就……有待商榷。它写后端的时候，会把所有业务逻辑全部挤在一个文件里，架构上我觉得不太对。我让 GPT 修了一下，GPT 能把架构分离开，但 V4 Pro 自己就没分开。我觉得主要是后训练还没训到位，所以还挺期待 6 月份的 V4.1 的。而且下半年 V4 Pro 还要降价，到时候主力说不定就变成它了——它也很快，质量也好。

就目前我在 Hermes Agent 里用过的模型来看，**最舒服的还是 DeepSeek 的模型**。

### 其他几家的简单感受

Kimi 的 K2.6 我还没试，准备这段试一下。从各种评测来看，K2.6 也是那种多面手、全能的选手。不过我能不能用上还不一定，之前在网页端用它，我还没说几句话呢，就“高峰时刻算力紧张”，一下给我分到 K2.6 快速版了。

千问 3.6 这边，因为核心人员走了，我实在没什么动力去体验，加上之前 Coding Plan 的种种遭遇，我不太想碰千问 3.6 Plus 了。再等等吧，看看千问后面还能不能搞出点新东西。

至于智谱的 GLM，我对这家公司一直没什么好感，感觉它某些行为有点像是国产版 Anthropic（笑）。Coding plan 什么的也抢不到，我就更没动力去试了。而且没记错的话，它 API 调用好像是按上下文的长度来计费的，这么一看性价比这块就更没吸引力了——比性价比，没人能打过 DeepSeek；想要极致性能，我直接去用 GPT。

所以综合这段时间在 Hermes Agent 里的体验，我还是更喜欢 DeepSeek V4。它性价比极高，能力也不比 GPT 5.5 低多少，虽然有时需要多来几个回合，但搭配着用的话，它现在就是我的主力模型。

还是那句话：希望国产模型早日真正崛起，让我们不用像现在这样，天天急头白脸地苦心钻研怎么钻国外的漏洞、薅 OpenAI 的羊毛去用最强大的模型。如果有一天，国产模型能做到开源比肩甚至超越顶级闭源模型，做到领域 SOTA，那对使用者来说真是天大的福音。
