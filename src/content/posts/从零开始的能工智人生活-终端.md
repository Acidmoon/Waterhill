# 从零开始的能工智人生活-和电脑直接对话：终端
> **前言**
本系列文章面向计算机与AI相关零基础的朋友，目的是让读者阅读实践后可以更好地驾驭电脑与如今的AI，受本人精力与能力限制，文章内容难免出现纰漏与不足，望读者在阅读时合理使用网络搜索工具进行深入了解。
> **适用对象**：刚高中毕业、没有系统接触过计算机的准大一新生
> **需要什么**：一台 Windows 电脑（本教程以 Windows 11 为例）、读完[上一章](/posts/从零开始的能工智人生活-认识你的电脑/)（至少要记得「路径」是什么）
---

**那个黑底白字的窗口，到底是什么？**

你可能见过这样的画面：电影里的黑客坐在电脑前，手指翻飞，敲出一个全是英文的黑窗口，电脑就「听话」地做了各种事。

那个黑窗口，就是**终端（Terminal）**。

你可能也遇到过这些情况，这堂课就是为你准备的：
- 跟着网上的教程操作，教程突然说「打开终端，输入以下命令」，你当场卡住
- 看到别人屏幕上黑底白字的窗口，觉得那是「高手的领域」，不敢碰
- 听说过「命令行」「Shell」「PowerShell」「cmd」这一堆词，完全分不清谁是谁
- 想用 AI 帮你操作电脑，但 AI 说「请你在终端里运行这个命令」，你不知道去哪里运行

上一章的结尾我们埋了一个伏笔：路径里的 `.` 和 `..` 在终端里非常有用。这一章，就来兑现这个承诺。

这堂课的目标很简单：**让你敢打开终端、看得懂提示、敲得出命令**。

------



## 第一部分：终端是什么？

### 1.1 点菜，还是直接跟后厨说话？

平时你用电脑，是这样的：想新建文件夹，就右键 → 新建 → 文件夹。每一个功能，界面上都有一个「按钮」等着你去点。

这就像**在餐厅点菜**：菜单上有什么，你才能点什么。菜单没写的菜，你点不了。

而终端是另一种方式和电脑交流：**你直接打字告诉电脑要做什么，电脑打字回答你**。

这就像**绕过菜单，直接冲进后厨跟厨师喊话**：「来一份番茄炒蛋！」——只要厨师听得懂，你甚至可以点菜单上没有的菜：「番茄炒蛋，不要番茄。」

| | 图形界面（鼠标点点点） | 终端（打字说话） |
| --- | --- | --- |
| 交流方式 | 看菜单、点按钮 | 打字下指令、看回复 |
| 上手难度 | 直观，所见即所得 | 需要记忆命令 |
| 效率上限 | 一次做一件事 | 一句话干一批活 |
| 类比 | 按菜单点菜 | 跟后厨直接喊话 |

### 1.2 一次分清楚这些名词

刚接触这块，你会遇到一串术语。别慌，用打电话来类比：

| 名词 | 是什么 | 类比 |
| --- | --- | --- |
| **终端（Terminal）** | 那个黑窗口本身，负责接收你打的字、显示电脑的回复 | 电话听筒 |
| **Shell** | 窗口背后「听懂你的话、去干活」的程序 | 电话那头的客服 |
| **PowerShell** | 微软出品的一款 Shell，Windows 自带 | 一位现代化客服 |
| **cmd** | Windows 上老一代的 Shell，比 PowerShell 年长得多 | 快退休的老客服 |
| **命令行（CLI）** | 「打字一问一答」这种交流方式本身 | 打字聊天 |

本教程以 **PowerShell** 为例，原因很简单：它是 Windows 官方现在主推的 Shell，你在 Windows 11 上打开「终端」时，默认接待你的就是它。至于 cmd，爷爷辈的东西，认识一下就好，先不用学。

### 1.3 为什么要学这个「老古董」？

图形界面明明这么好用，为什么还要学打字？三个理由：

1. **很多活，一句话顶一百次点击**。想把这个文件夹里所有 `.jpg` 图片改成统一格式名字？鼠标要点到手抽筋，终端一行命令搞定（这是后面章节的内容）。
2. **很多工具，只肯用打字的方式跟你交流**。程序员的世界里大量工具没有按钮可点。
3. **AI 时代的硬通货**。你让 AI 帮你处理电脑上的事时，它最常用的回答就是「请在终端运行这个命令」。看不懂命令，AI 的手就伸不到你的电脑里。学完这一章，你至少能看懂 AI 给你的命令大概在干什么，而不是闭着眼睛粘贴。

## 第二部分：打开你的第一个终端

### 2.1 三种打开方式

**方式一：开始菜单搜索**

按键盘上的 `Win` 键（就是那个窗户徽标键），直接打字搜索「终端」，回车。![开始菜单搜索终端.png](/images/terminal-01-start-menu-search.png)

**方式二：Win + X 快捷菜单**

同时按下 `Win + X`，在弹出的菜单里点**「终端」**。![WinX菜单.png](/images/terminal-02-winx-menu.png)

注意菜单里还有一个**「终端（管理员）」**——带「管理员」三个字的意味着更大的权限，能改动系统级的东西。新手阶段用不到它，也先别用它：权限大，意味着破坏力也大。

**方式三：在文件夹里直接打开（本章演示用）**

还记得上一章「高手操作」表格里提到的「在终端中打开」吗？在任意文件夹的空白处右键（如果你的右键菜单里没有，试试按住 `Shift` 再右键），点**「在终端中打开」**，终端打开后就直接出生在这个文件夹里——这个细节马上就会用到。

### 2.2 先建一个临时目录

从这一章开始，我们约定：**不在你的真实文件里练手，所有命令都在一个专门的练习文件夹里执行**——这样手滑删错了也不心疼。

为什么这么谨慎？一是终端里「不进回收站的删除」真实存在，在空地上手滑，最多损失一个新建的文件夹；二是，说实话——终端打开时默认的「用户主目录」（就是 `C:\Users\你的用户名` 那个文件夹），而作者本人的用户目录早被系统和各种软件塞得乱七八糟、惨不忍睹，实在不适合出镜。与其在一堆杂物里面演示，不如专门开辟一块干净的空地：看着清爽，也不会误碰真实文件。

请用上一章学会的方法，在你空间最宽裕的盘（比如 D 盘；如果你的电脑没有 D 盘，建在 C 盘或者桌面也完全可以，后面所有步骤一模一样，只是提示符里的盘符不同）新建一个文件夹，命名为「终端练习」，然后在它的文件夹空白处右键 →「在终端中打开」。

打开后，你会看到这样的窗口：![终端第一眼.png](/images/terminal-03-first-look.png)

窗口里大部分是黑的。提示符上面那两行英文（`Windows PowerShell / Copyright ...`）是 PowerShell 开机时的「自报家门」，每个人电脑上的措辞可能略有不同，不用管它。真正重要的是在闪烁光标等你的这一行：

```
PS D:\终端练习>
```

这一行叫**提示符（prompt）**，每个部分都有含义：

| 部分 | 含义 |
| --- | --- |
| `PS` | 「PowerShell 」，告诉你现在接待你的 Shell 是谁 |
| `D:\终端练习` | **你当前所在的位置**——就是上一章学的路径 |
| `>` | 「请下指令」，后面闪的就是光标 |

发现了吗？终端打开的瞬间就回答了上一章最重要的那个问题——**我现在在哪**。提示符显示的位置，就是你的位置。你在文件管理器里「站在哪个文件夹」，对应到终端里，就是提示符里显示的那个路径。

> **检查点**：如果你是用「开始菜单搜索」打开的终端，提示符会显示 `PS C:\Users\你的用户名>`——那说明你还在默认的位置。输入 `cd D:\终端练习`（没有 D 盘就换成你的实际路径）回车，再继续往下。

> **注意**：终端不会因为你说错话而爆炸。打错命令，最多得到一段红色报错，没有任何损失。放心大胆地敲。

## 第三部分：起步命令

下面每个命令都请你在自己的「终端练习」里亲手敲一遍。**敲命令的规矩：输入命令 → 按回车 → 看回复**。

先说一个特别重要、但教程经常忘记交代，而且也是初上手的朋友经常犯的小错误：后文的代码块里会看到 `PS D:\终端练习>` 这样的开头，那是**提示符**，由电脑自动显示——**你只需要敲提示符后面的命令本身**，`PS D:\终端练习>` 这一段不要敲进去。

### 3.1 pwd——我在哪？

虽然提示符已经告诉了你位置，但有时屏幕刷得太乱，我们想要一个明确的回答：

```
PS D:\终端练习> pwd

Path
----
D:\终端练习
```

![pwd.png](/images/terminal-04-pwd.png)

`pwd` 是 print working directory（打印当前工作目录）的缩写，意思是「报出我现在的位置」。终端回答：`D:\终端练习`。

### 3.2 mkdir——无中生有，造一个文件夹

在终端里造文件夹，只需要一句话：

```
PS D:\终端练习> mkdir 大学四年
```

`mkdir` 是 make directory（造目录）的缩写。回车后 PowerShell 会汇报：在哪个目录、新建了什么。![mkdir和ls.png](/images/terminal-05-mkdir-ls.png)

如果文件夹名字里带空格，比如 `我的 资料`，要用引号包起来写成 `mkdir "我的 资料"`——不然终端会把 `我的` 和 `资料` 当成两个名字，搞不清你要建哪一个。没空格的名字不用引号。

### 3.3 ls——这里有什么？

造完之后看看它在不在。`ls` 是 list（列出）的缩写，作用是「列出当前位置所有东西」（3.2 那张截图的下半部分，就是 `ls` 的实际样子）：

```
PS D:\终端练习> ls

    目录: D:\终端练习

Mode                 LastWriteTime         Length Name
----                 -------------         ------ ----
d-----        2026/8/28              0:22                大学四年
```

这张输出表就是终端版的「文件管理器窗口」，每一列的含义：

| 列 | 含义 |
| --- | --- |
| `Mode` | 类型。以 `d` 开头是文件夹（directory），以 `-` 开头是文件，后面那一串字母暂时不用管 |
| `LastWriteTime` | 最后一次修改时间 |
| `Length` | 文件占的空间（单位是字节，一个汉字大约占 2 个字节；文件夹不显示大小，所以是空的） |
| `Name` | 名字 |

还有一个小知识：**「命令执行完没有任何输出」也是一种回答**，通常意味着「已执行」。

### 3.4 cd——我要去那！

现在进到刚造好的文件夹里去。`cd` 是 change directory（更换目录）的缩写：

```
PS D:\终端练习> cd 大学四年
PS D:\终端练习\大学四年> mkdir 大一上
PS D:\终端练习\大学四年> cd 大一上
PS D:\终端练习\大学四年\大一上> pwd

Path
----
D:\终端练习\大学四年\大一上
```

（中间那次 `mkdir 大一上` 也汇报了一张表格，和 3.2 的输出一个样子，这里就不重复贴了——下面这张截图里能看到。）

![cd深入.png](/images/terminal-06-cd-mkdir-pwd.png)

注意看提示符的变化：每执行一次 `cd`，提示符就跟着你走到了新位置，像游戏里的坐标一样实时更新。最后 `pwd` 确认：我们真的站在三层深的文件夹里了。

另外注意，我们进 `大学四年` 时写的是 `cd 大学四年`，而不是 `cd D:\终端练习\大学四年`——上一章讲的**相对路径**在这里派上用场了：你已经站在 `D:\终端练习` 里了，只需要说「去里面的大学四年」，不必把整个地址从头念一遍。

### 3.5 cd ..——退回上一级

想退回上一级文件夹（从 `大一上` 退回 `大学四年`），用 `..`：

```
PS D:\终端练习\大学四年\大一上> cd ..
PS D:\终端练习\大学四年> pwd

Path
----
D:\终端练习\大学四年

PS D:\终端练习\大学四年> cd 大一上
```

![cd点点.png](/images/terminal-07-cd-dotdot.png)

`cd ..` 就是「往回走一层」。想连退两层就写 `cd ..\..`。配合上一章的表格复习一下：

| 符号 | 含义 |
| --- | --- |
| `.` | 当前文件夹（就站在这儿） |
| `..` | 上一级文件夹（回头走一层） |


### 3.6 echo 和 >——在终端里写一张纸条

想在终端里创建一个文件？两条命令配合：

```
PS D:\终端练习\大学四年\大一上> echo "开学第一天，一切顺利" > 日记.txt
```

`echo` 就是复读机：你说什么，它原样「喊」出什么。而单独的 `>` 符号意思是「别喊出来了，**把你喊的内容写进这个文件**」——这就是造文件的终端方式。

顺带一句：如果 `>` 后面的文件名已经存在，`>` 会把旧内容**整个覆盖**掉——会被重写，而非接着往后写。

用 `ls` 验证一下，`日记.txt` 真的躺在那里了：![echo建文件.png](/images/terminal-08-echo-create-file.png)

### 3.7 cat 和 rm——看一眼，然后删掉

想不打开文件管理器就看看文件里写了啥，用 `cat`（本义是 concatenate「拼接」——把多个文件首尾拼在一起打印出来，平时我们最常用它来显示一个文件的内容，记住「显示文件内容」就行）：

```
PS D:\终端练习\大学四年\大一上> cat 日记.txt
开学第一天，一切顺利
```

看完了，删掉它，用 `rm`（remove，移除）：![cat和rm.png](/images/terminal-09-cat-rm.png)

```
PS D:\终端练习\大学四年\大一上> rm 日记.txt
PS D:\终端练习\大学四年\大一上> ls
PS D:\终端练习\大学四年\大一上>
```

`rm` 执行完一声不吭，`ls` 一看——空空如也。删掉了。


**`rm` 是本章最危险的一条命令，请记住三点：**
1. 用 `rm` 删掉的东西**不进回收站，直接消失**，没有「手滑了 Ctrl+Z」的机会；
2. 删除之前，先 `pwd` 看一眼自己站在哪——「在哪个文件夹里执行 rm，删的就是那个文件夹里的东西」，站错位置再动手，删的就是别人的文件；
3. 删**文件夹**时终端会多一道保险：空文件夹直接删；非空文件夹会弹出 `Y/N` 确认——注意**默认值是 Y，直接回车等于回答「是」**，想反悔就按 `N`。
:::

## 第四部分：让终端用起来更省力的四个技巧

### 4.1 Tab 补全：名字太长？按 Tab 让它猜

先退回顶层：输入 `cd ..\..`（连退两层）让提示符变回 `PS D:\终端练习>`，再跟我做。

目录名字太长，手打太累？只打前几个字，按键盘上的 `Tab` 键，终端自动帮你补全。比如只输入 `cd 大`，按一下 `Tab`，它就自动变成了：

```
cd 大学四年
```

如果开头相同的名字有好几个，连按 `Tab` 会在它们之间轮换。这个技巧能让你的打字量减少一半以上，且能有效防止拼错名字。

### 4.2 上下方向键：翻出历史命令

按键盘的 `↑` 方向键，刚才敲过的命令会一条条翻出来。发现自己五分钟前敲过一条长命令想再跑一次？按几下 `↑` 找到它，直接回车。不用重新打。

### 4.3 cls：擦黑板

屏幕太乱，输入 `cls`（**c**lear **s**creen 的缩写，clear 也行），整块黑板瞬间擦干净，光标回到左上角。放心，擦的只是「显示」，你创建的文件都还在。

### 4.4 复制粘贴：终端也支持 Ctrl+C / Ctrl+V

终端里可以 `Ctrl + V` 粘贴（或在窗口里点右键粘贴）。这意味着你可以从教程或 AI 的回答里复制命令来执行。但是大部分时间还是更推荐在powershell里选中文本后点击右键——复制；在光标闪烁的时候（终端等待输入）右键就是粘贴。

:::caution
**但请养成一个习惯：粘贴之前，先把命令读一遍。**

网络上有一种攻击方式，就是诱导人把恶意命令粘进终端。看不懂的命令不粘、来路不明的「一键优化」「一键修复」不粘。AI 给你的命令也一样——这一章教你的 `pwd`、`ls`、`cd`、`mkdir`，够你看懂大部分命令「在哪个文件夹、对什么东西、做什么动作」了。
:::

顺便预告一个同键不同命的功能：终端里的 `Ctrl + C` 还有一个身份——**强制打断正在执行的命令**。以后遇到命令卡住跑不完，按 `Ctrl + C` 就是急刹车（所以有时候在终端里复制文字会发现 `Ctrl + C` 不好使，先用鼠标选中文字再复制就好）。

## 第五部分：命令的「外号」哲学（选学）

这一节以了解为主，不动手敲也没关系，读完有个印象就行。

### 5.1 你敲的其实是缩写

学到现在你可能会疑惑：`ls`、`pwd` 这些词是谁规定的？真相是：它们都是「外号」。看看这一章命令的本名：

| 你敲的（外号/别名） | 本名（完整命令） | 本名的意思 |
| --- | --- | --- |
| `pwd` | `Get-Location` | 获取位置 |
| `ls` | `Get-ChildItem` | 获取子项目（文件夹里的孩子们） |
| `cd` | `Set-Location` | 设置位置 |
| `mkdir` | `New-Item` | 新建项目（文件夹版）* |
| `echo` | `Write-Output` | 写出内容 |
| `cat` | `Get-Content` | 获取内容 |
| `rm` | `Remove-Item` | 移除项目 |
| `cls` | `Clear-Host` | 清空屏幕 |

\* `mkdir` 有点特殊：它不是单纯的别名，而是一个「函数」，内部帮你执行 `New-Item -Type Directory`。所以用 `Get-Command mkdir` 查它，出来的类型是 `Function` 而不是 `Alias`——较真的读者别慌，是它不是我写错了。

外号好打，本名好懂。想知道某个外号的本名，用 `Get-Command` 查询：

```powershell
Get-Command rm
```

输出类似：

```
CommandType     Name              Version    Source
-----------     ----              -------    ------
Alias           rm -> Remove-Item
```

### 5.2 PowerShell 起名的规律：动词-名词

仔细看本名，全是「**动词-名词**」结构：`Get-Location`（获取-位置）、`Remove-Item`（移除-条目）、`Set-Location`（设置-位置）……

这是 PowerShell 的命名军规，**看名字就能猜出功能**。认识几个高频动词，以后见到陌生命令也能猜个八九不离十：

| 动词 | 意思 | 例子 |
| --- | --- | --- |
| `Get` | 获取、查看 | `Get-Content` 看内容 |
| `New` | 新建 | `New-Item` 建新东西 |
| `Set` | 设置、修改 | `Set-Location` 改位置 |
| `Remove` | 删除 | `Remove-Item` 删东西 |
| `Copy` | 复制 | `Copy-Item` 复制 |
| `Move` | 移动 | `Move-Item` 搬家 |
| `Clear` | 清空 | `Clear-Host` 清屏 |

这也是为什么网上教程和 AI 有时给你 `ls`、有时给你 `Get-ChildItem`——它们是同一个命令的两个名字，效果完全一样。两个都认识，别人的命令你就都能看懂了。

## 第六部分：出错怎么办？

新手用终端，一定会遇到满屏红字。先看一张真实的红字（我把 `cd 大一上` 手滑敲成了 `cd 大一上上`）：![红字报错.png](/images/terminal-10-error-message.png)

别怕，逐句翻译一下这段红字：

| 红字原文 | 人话 |
| --- | --- |
| `cd : 找不到路径"…\大一上上"，因为该路径不存在。` | 你要去的文件夹不存在（多半是名字打错了） |
| `所在位置 行:1 字符: 1` | 出错的是你输入的第 1 行第 1 个字符附近 |
| `+ CategoryInfo / FullyQualifiedErrorId` | 给程序员看的错误编号，新手可以无视 |

规律总结：

- **红字 = 报错，不是爆炸**。终端只是在告诉你「这事没办成，原因如下」——注意上面截图里，报错之后提示符照常出现，终端活得好好的。
- **读红字的第一行**，往往就是原因。找不到路径、找不到命令、权限不够，是新手三大件。
- **看不懂就把红字复制下来**，去搜索，或者直接问 AI。从这一章开始，「把报错喂给 AI」是你排障的基本功。

:::note
**思考题参考答案**：红字会说「找不到路径」。因为终端只认识两个带点的特殊名字：`.`（当前）和 `..`（上一级）。`...` 在终端眼里不是什么特殊符号，只是一个名字叫「...」的文件夹——而它并不存在，所以报错。
:::
